# Игра — карта и анимации

Здесь начинается сама игра: карта города и библиотека анимаций для персонажей.
Модели, из которых всё собрано, лежат в [`models/`](../models).

```
game/
├── map/
│   ├── city_map.svg          # вектор-карта Marisol, 2400×1700
│   ├── city_map.png          # растровая версия
│   └── MAP.md                # районы, дороги, POI, перевод координат в мир
├── animations/
│   ├── player.glb            # игрок: 198 клипов
│   ├── npc_civilian.glb      # гражданские NPC: 120 клипов
│   ├── npc_police.glb        # полиция: 120 клипов
│   ├── clips.json            # машинный манифест: имя, категория, длительность, цикл
│   ├── ANIMATIONS.md         # полные таблицы клипов
│   └── viewer.html           # просмотрщик анимаций в браузере
└── tools/
    ├── animlib.py            # запись glTF-анимаций в GLB, позы, риг
    ├── clips.py              # генераторы поз: локомоция, idle, огнестрел, экшены
    ├── actions.py            # ключевые кадры: двери, касса, паркур, реакции, смерть
    ├── actions2.py           # бой, оружие, полиция, гражданские
    ├── build_animations.py   # сборка трёх GLB + манифест + документация
    └── make_map.py           # генератор карты
```

## Карта

- Город **Marisol** (Leonida), 12 × 8.5 км, масштаб 1 px = 5 м.
- 13 районов: Downtown, Barrio Sol, Sunset Palms, Ocean Strip, Marina Real,
  Port Marisol, Zona Industrial, Colinas Altas, Costa Verde Golf, Pantano Verde,
  аэропорт, стадион, кампус.
- Кольцевое шоссе, магистрали, сетка центра, железная дорога с вокзалом, паром,
  мосты, река и каналы.
- 21 точка интереса: полиция, больница, магазины, гараж, убежище, еда, одежда,
  оружие, банк, заправка, порт, развлечения.

Подробности, таблицы районов и формула перевода координат карты в мир —
[`map/MAP.md`](map/MAP.md).

## Анимации

**438 клипов** в трёх наборах, все — обычные glTF-анимации внутри GLB
(имя клипа в `animations[].name`, метаданные в `animations[].extras`).

| Набор | Клипов | Что внутри |
| --- | ---: | --- |
| `player.glb` | 198 | 49 вариантов ходьбы/бега/приседа, 19 idle, удары и захваты, 29 клипов огнестрела (стойки, выстрелы, перезарядки, укрытия), паркур, двери, касса, машина, реакции и смерти |
| `npc_civilian.glb` | 120 | прогулки и пробежки, 14 idle, телефон, еда, магазины, работа, танцы, паника, сдача в плен, смерти |
| `npc_police.glb` | 120 | патруль и бег, стойки с пистолетом/винтовкой/дробовиком, стрельба из укрытий, наручники, обыск, рация, штраф, тазер, дубинка, щит, фонарь |

Риг у всех один — mixamo, 66 костей, поэтому клипы ретаргетятся по именам костей на
остальных персонажей из `models/sketchfab/` (там 11 человеко-моделей).

### Как посмотреть

```bash
python3 -m http.server 8000     # из корня репозитория
# открыть http://localhost:8000/game/animations/viewer.html
```

Вьюер: переключатель наборов, список клипов по категориям, пауза, ползунок времени,
орбитальная камера. Three.js подгружается с CDN, поэтому нужен интернет.

### Как пересобрать

```bash
python3 game/tools/build_animations.py
```

Нужен `numpy`. Скрипт берёт персонажей из `models/sketchfab/`, печёт клипы в
`game/animations/*.glb` и перегенерирует `clips.json` и `ANIMATIONS.md`. Все клипы
заданы в `clips.py` / `actions.py` / `actions2.py` — правьте параметры и
пересобирайте.

### Как пересобрать карту

```bash
python3 game/tools/make_map.py
```

SVG перезаписывается. PNG рендерится любым конвертером, например:

```bash
npx @resvg/resvg-js city_map.svg city_map.png
```

## Ограничения

- Клипы **процедурные**: это аккуратные заготовки под игру, а не mocap. Циклы
  локомоции читаются хорошо, тонкая моторика (пальцы, точный хват оружия) не
  анимируется — кисти ставятся приблизительно, без IK на оружие.
- Все клипы **in-place**: перемещение по миру делает движок.
- Масштаб моделей — сантиметры (таз 87–137 units), Y вверх.
- Карта — художественная схема, а не топографически точный план: высоты и
  дорожный граф ещё не сделаны.

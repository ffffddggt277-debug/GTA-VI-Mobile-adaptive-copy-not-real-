# GTA VI: Leonida — Unity-проект

Фанатский мобильный концепт GTA VI: полноценная игра на Unity 6 (URP не используется —
см. «Ограничения»), собирается в APK для Android. Ни одного импортированного ассета:
город, персонажи, машины, текстуры, музыка и звуки генерируются кодом на C#.

## Как собрать APK

```bash
bash tools/setup-unity-android.sh     # один раз: Unity 6.3 + JDK 17 + Android SDK 35
bash tools/build-apk.sh               # сборка Builds/GTA6-Leonida.apk
```

Первый запуск требует активированной лицензии Unity (бесплатная Personal). Без неё
редактор не открывает проект вообще — `tools/build-apk.sh` печатает пошаговую
инструкцию (сгенерировать `.alf` → license.unity3d.com/manual → положить `.ulf`
в `~/.local/share/unity3d/Unity/Unity_lic.ulf`).

## Как проверить без лицензии

Лицензия нужна только для запуска редактора. Код проверяется без неё:

```bash
bash tools/unity-compile.sh                 # весь runtime-код против сборок Unity
bash tools/unity-compile.sh --editor x.dll  # плюс Assets/Editor/BuildScript.cs
bash tools/run-core-tests.sh                # 580 проверок чистой логики на .NET Unity
```

`tools/run-core-tests.sh` реально исполняет правила игры: экономику, розыск,
состояния оружия, сохранения, локализацию и все пять миссий от начала до конца.

## Что внутри

| Слой | Файл | Содержимое |
| --- | --- | --- |
| Данные | `Core/GameData.cs` | 12 районов, 5 оружий, 9 машин, 6 радиостанций, 16 приложений, 22 контакта, 5 миссий |
| Тексты | `Core/Loc.cs` | RU/EN таблица (~170 ключей), числа, время, имена дней |
| Правила | `Core/Rules.cs` | урон/броня/стамина, магазины и патроны, розыск 1–5, машина состояний миссий, сохранение в текст |
| Мир | `Game/World.cs` | сетка дорог, кварталы, дома/башни/отели/склады, пальмы, фонари, пляж, океан, AABB-коллизии, текстура карты 1024² |
| Персонажи | `Game/Actors.cs` | процедурный риг (5 мешей), игрок, пешеходы, полицейские, попадания |
| Транспорт | `Game/Vehicles.cs` | 9 типов машин, аркадная физика, свет, трафик |
| Бой | `Game/Combat.cs` | hitscan, трассеры, эффекты, авто-прицел, полиция и погони |
| Камера | `Game/CamRig.cs` | третье лицо, орбита по тачу, коллизии, зум при прицеле |
| UI | `Game/Ui.cs`, `Hud.cs`, `PhoneUI.cs`, `MapScreen.cs`, `MenuUI.cs` | IMGUI: HUD, миникарта, телефон с 16 приложениями, карта с метками, меню и настройки |
| Звук | `Game/AudioDirector.cs` | синтез выстрелов, двигателя, сирены, дождя и шести радиостанций (8 с луп) |
| Сборка | `Assets/Editor/BuildScript.cs` | настройки Android (Mono, ARM64+ARMv7, minSdk 25, landscape) и сборка APK |

Игра стартует из пустой сцены: `Bootstrap.cs` создаёт `GameRoot`, тот строит мир
и запускает цикл. Поэтому в репозитории нет ни сцен, ни префабов, которые могут
рассинхронизироваться с кодом.

## Управление

- Левая половина экрана — виртуальный джойстик (до упора = бег).
- Правая половина — камера; FIRE/AIM/RLD/JUMP/CAR/SWAP/TEL/MAP/II — кнопки.
- На ПК: WASD, мышь, Shift, Space, F, E, Q, R, Tab, M, Esc.

## Ограничения

- **Без лицензии Unity собрать APK нельзя** — это единственное, что осталось для
  готового файла; весь код и сборочный скрипт готовы.
- Рендер — встроенный (Built-in) пайплайн, а не URP: URP-ассет создаётся только
  редактором, а проверить его без лицензии невозможно. Визуально для такого
  контента разницы нет: направленный свет с тенями, процедурный скайбокс, туман,
  эмиссивные окна и ночь.
- Вся графика — плоские меши с палитровой текстурой (одна на материал). Это даёт
  стабильные 60 fps на телефоне, но не фотореализм. «Как в GTA 6» — недостижимо:
  там сотни художников и годы работы; здесь честный играбельный концепт.
- Эмулятора Android в этой VM нет — APK можно собрать, но не запустить здесь.
